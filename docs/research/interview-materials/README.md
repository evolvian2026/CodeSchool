# Interview materials

Materials for the [school interview plan](../school-interview-plan.md).

| File | Use it for |
|---|---|
| [intro-letter.md](intro-letter.md) | One-page request to principals and coordinators, plus the opening and consent script read at every interview |
| [level-b3-paper-prototype.md](level-b3-paper-prototype.md) | The printed sample lesson (Class 4, conditionals) that teachers walk through, with an answer key, an observation sheet and a student sheet |
| [device-audit-sheet.md](device-audit-sheet.md) | Counting working devices, lab time, internet and power with the computer teacher |
| [tracking-sheet-template.csv](tracking-sheet-template.csv) | Tracking schools S01-S20 from first contact to pilot interest. Opens in Excel or Google Sheets |

## Keep interview data private

**This repository is public.** Don't commit anything with names, phone numbers, emails or details that could identify a school.

- Copy the tracking sheet to `tracking-sheet.private.csv` (or into a private Google Sheet) before adding contacts. Files named `*.private.*` are ignored by Git.
- Save interview notes in `docs/research/interviews/`. That folder is ignored by Git, so notes stay on this computer only. Back them up somewhere private.
- Only the anonymised findings memo should be committed.

## Printing

Markdown doesn't print well straight from GitHub. To print, open the file in VS Code or a Markdown viewer and print to PDF, or paste it into Word or Google Docs. Print the prototype's student sheet (page 4) once per pair of students.
