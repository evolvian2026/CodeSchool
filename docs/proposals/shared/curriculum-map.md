## Appendix A. Chapter-by-chapter curriculum map

CBSE's CT&AI handbooks follow the NCERT mathematics textbook chapter by chapter, so CodeSchool does the same. For every chapter, the map below shows the main computational-thinking (CT) skill CBSE's handbook practises and the CodeSchool level or activity that adds a "now you build it" step. **This is the planned mapping for the pilot; it will be confirmed with the school's teachers and adjusted if the school follows a different chapter order.**

CodeSchool levels are grouped in bands. **Band B (Builders)** covers Classes 3-5: B1 sequences and loops, B2 events and patterns, B3 conditionals (if-then-else), B4 nested and repeat-until loops, B5 variables and inputs, B6 CT puzzle strategies, B7 capstone game. **Band C (Makers)** covers Classes 6-8: C1 functions, C2 lists and data, C3 AI literacy I, C4 the code behind the blocks, C5 reading code, C6 writing simple code, C7 AI literacy II, C8 projects.
